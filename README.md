# campus-events
A small web app that I will modify in the future. It built with a Node.js and an Angular client.

## How to run

### Server (port 3000)
'''bash
cd server
node hello.js
'''

### Client (port 4200)
'''bash
cd client
npm install
ng serve
'''

Open http://localhost:4200 in your browser. Both the server and the client must be running at the same time.
